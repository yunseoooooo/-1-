사람의 역할

컴퓨터가 모든 것을 판단하는 것이 아니라, 사람은 목적과 상황 및 맥락을 이해하고 결과가 공정하고 적절한지 판단해야 한다.

## 2-2. 

데이터는 관찰, 측정, 조사 등을 통해 얻은 값이나 사실을 표현한 것이다.

데이터에는 숫자뿐만 아니라 다음과 같은 것들이 포함된다.
	•	문자
	•	사진
	•	음성 및 소리
	•	위치
	•	날짜
	•	센서값

또한 데이터는 목적과 맥락에 따라 해석이 달라질 수 있다.

## 2-3. 
	•	입력: 컴퓨터가 처리할 데이터와 명령을 받아들이는 과정
	•	처리: 입력된 데이터를 프로그램의 명령에 따라 변환하는 과정
	•	출력: 처리 결과를 사용자나 다른 시스템에 전달하는 과정
	•	저장: 데이터나 프로그램, 처리 결과를 나중에 다시 사용할 수 있도록 보관하는 과정
	•	공유: 데이터를 다른 컴퓨터나 시스템으로 전달하는 것

저장은 마지막 단계에서만 일어나는 것이 아니라, 처리 도중 데이터를 읽어오거나 중간 결과를 보관하는 과정에서도 이루어질 수 있다.

	•	장치 관리

장치 드라이버
	•	운영체제가 하드웨어와 통신할 수 있도록 도와줌

응용 소프트웨어

	•	저장장치

## 3-2. 

컴퓨터에서는 전압 등의 상태를 이용하여 0과 1을 표현한다.
	•	0 또는 1 = 1비트(bit)
	•	비트 하나는 두 가지 상태를 표현할 수 있음
	•	0 / 1
	•	False / True

여러 비트와 그에 대한 해석 규칙을 조합하면 숫자와 문자를 표현할 수 있으며, 사진, 음악, 동영상 등 다양한 정보를 표현할 수 있다.

## 3-3. 
	•	비트(bit): 0과 1 중 하나를 나타내는 가장 작은 정보 단위
	•	바이트(byte): 8개의 비트를 묶은 단위

바이트는 파일 크기나 저장 용량을 표현할 때 기본이 되는 단위이다.

## 3-4. 

컴퓨터는 편리한 개인 도구를 넘어 현대사회를 움직이는 중요한 기반이 되었다.

	•	산업: 반복적인 계산과 기록을 자동화하여 생산성을 높임
	•	공장: 센서와 로봇을 활용하여 제품을 생산하고 품질을 검사함
	•	기업: 판매 및 고객 데이터를 분석하여 의사결정을 지원함
	•	의사소통과 문화: 인터넷과 모바일 컴퓨터를 통해 시간과 장소의 제약을 줄임
	•	콘텐츠: 메시지, 영상통화, 음악, 영화, 게임 등 다양한 서비스를 이용할 수 있음

컴퓨터는 매우 민감한 개인정보를 다루기도 하기 때문에 정확한 보안과 책임 있는 사용이 중요하다.
